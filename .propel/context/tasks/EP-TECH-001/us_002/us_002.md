# US-002: Establish Test and Logging Foundation

## Epic Link
- Epic ID: EP-TECH-001
- Epic Name: Platform and Delivery Bootstrap

## User Story
As a tech lead,
I want baseline unit and e2e test scaffolding plus structured logging utilities,
so that feature work is verifiable and observable from the first sprint.

## Business Value
- Prevents regressions during rapid hackathon delivery.
- Standardizes log shape for downstream audit requirements.

## Acceptance Criteria
1. Unit test framework is configured and sample tests execute successfully.
2. E2E test framework is configured and a smoke scenario runs.
3. Shared logger utility emits structured JSON with timestamp and level.
4. API request correlation ID is generated and propagated to logs.
5. CI-ready scripts exist for lint, test, and build commands.

## Implementation Evidence Checklist (2026-07-29)
1. AC-001: **Pass**
	- Evidence: Vitest baseline configured with setup hooks and sample suites in `tests/lib/api-response.test.ts` and `tests/lib/config.test.ts`.
	- Validation: `npm run test` passed.
2. AC-002: **Pass**
	- Evidence: Playwright framework configured in `playwright.config.ts` with smoke scenario in `tests/e2e/smoke.spec.ts`.
	- Validation: `npm run test:e2e` passed (2 smoke tests).
3. AC-003: **Pass**
	- Evidence: Shared logger utility in `lib/logger.ts` emits structured JSON fields (`timestamp`, `level`, `message`, `context`).
4. AC-004: **Pass**
	- Evidence: Correlation utilities in `lib/correlation-id.ts` and route wiring in `app/api/*/route.ts` propagate and reuse `x-correlation-id`.
	- Validation: Manual request test confirmed generated and forwarded correlation IDs.
5. AC-005: **Pass**
	- Evidence: CI script catalog defined in `package.json` for `lint`, `test`, `test:e2e`, and `build`.
	- Validation: All scripts passed in local sequence.
