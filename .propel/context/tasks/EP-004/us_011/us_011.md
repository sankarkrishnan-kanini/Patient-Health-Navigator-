# US-011: Capture Full Audit Trail with Guardrail Metadata

## Epic Link
- Epic ID: EP-004
- Epic Name: Auditability and Governance

## User Story
As an operations reviewer,
I want every user and assistant turn persisted with guardrail metadata,
so that interactions are auditable for quality and safety review.

## Business Value
- Provides governance evidence required by stakeholders.
- Supports post-demo troubleshooting and incident analysis.

## Acceptance Criteria
1. Each turn is logged with conversation ID, role, content reference, and timestamp.
2. Guardrail events are logged with rule ID, triggered status, and reason.
3. Sensitive log fields are encrypted with key version metadata.
4. Logs are queryable by conversation ID and time range.
5. Missing required audit fields fail validation before persistence.
