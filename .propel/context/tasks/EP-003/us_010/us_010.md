# US-010: Enforce Off-Scope and Medication Safety Boundaries

## Epic Link
- Epic ID: EP-003
- Epic Name: Clinical Guardrails and Escalation

## User Story
As a clinical governance reviewer,
I want deterministic boundary responses for diagnosis, dosage change, and lab interpretation requests,
so that the assistant never provides prohibited clinical advice.

## Business Value
- Prevents unsafe behavior outside assistant scope.
- Strengthens trust and compliance posture for demo and beyond.

## Acceptance Criteria
1. Diagnosis requests return boundary response with care-team handoff.
2. Dosage change or medication stop requests return refusal and escalation guidance.
3. Lab interpretation requests do not produce clinical judgment.
4. Post-generation guardrail check blocks prohibited model output if it appears.
5. Boundary scenarios are included in deterministic test harness.
