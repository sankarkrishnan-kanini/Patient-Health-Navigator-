# US-004: Prepare Showcase Patient Cohort

## Epic Link
- Epic ID: EP-DATA-001
- Epic Name: Synthetic Data Foundation

## User Story
As a demo lead,
I want a curated set of 5 to 10 diverse synthetic patient profiles,
so that the demo can show realistic conversations across multiple clinical scenarios.

## Business Value
- Improves demo clarity and judge confidence in personalization quality.
- Covers diverse use cases including chronic and acute symptom prompts.

## Acceptance Criteria
1. At least five and up to ten patient profiles are available for selection.
2. Profiles include varied clinical contexts such as chronic disease and preventive care.
3. Each profile has complete fields required by chat personalization.
4. A profile summary view payload is generated for UI display.
5. Data refresh process preserves stable profile IDs for demo scripts.
