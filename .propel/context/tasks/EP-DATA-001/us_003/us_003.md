# US-003: Ingest and Normalize Synthea Clinical Data

## Epic Link
- Epic ID: EP-DATA-001
- Epic Name: Synthetic Data Foundation

## User Story
As a data engineer,
I want to ingest Synthea resources and normalize them into a patient context schema,
so that the navigator can provide reliable personalized responses.

## Business Value
- Establishes data reliability for safety and personalization.
- Reduces model hallucination risk by grounding responses in structured context.

## Acceptance Criteria
1. Pipeline ingests Patient, Condition, MedicationRequest, CarePlan, Encounter, and Observation resources.
2. Normalized schema stores active conditions, medications, care tasks, appointments, observations, and SDOH flags.
3. Data validation catches missing required attributes and reports errors.
4. Reprocessing does not create duplicate patient context records.
5. Source-to-schema lineage metadata is captured.
