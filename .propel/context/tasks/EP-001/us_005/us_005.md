# US-005: Implement Patient Selection and Profile Panel

## Epic Link
- Epic ID: EP-001
- Epic Name: Patient Context Foundation

## User Story
As a patient user,
I want to select a synthetic patient and view their summary next to chat,
so that I can trust responses are based on the selected profile.

## Business Value
- Delivers visible personalization and transparency in the demo.
- Reduces confusion around which profile is active.

## Acceptance Criteria
1. User can choose a profile from the showcase list before starting chat.
2. Selected profile summary displays conditions, medications, care tasks, and upcoming visits.
3. Chat remains disabled until profile loading is complete.
4. Active profile indicator remains visible during conversation.
5. Profile load failure shows retry guidance.
