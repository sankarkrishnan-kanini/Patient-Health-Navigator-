# US-006: Bind Conversation Sessions to Patient Context

## Epic Link
- Epic ID: EP-001
- Epic Name: Patient Context Foundation

## User Story
As the conversation service,
I want each conversation session to bind to one selected patient context,
so that generated responses remain accurate and session-safe.

## Business Value
- Prevents cross-patient data leakage.
- Ensures deterministic context injection for downstream LLM calls.

## Acceptance Criteria
1. A unique conversation ID is created on session start.
2. Session stores selected patient ID and context snapshot reference.
3. Every chat request includes bound session and patient context.
4. Session reset clears prior patient context and turn memory.
5. Cross-session isolation tests pass.
