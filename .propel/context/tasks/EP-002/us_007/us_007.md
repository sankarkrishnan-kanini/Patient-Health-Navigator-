# US-007: Deliver Personalized Medication and Condition Guidance

## Epic Link
- Epic ID: EP-002
- Epic Name: Conversational Guidance Core

## User Story
As a patient user,
I want plain-language answers to medication and condition questions using my selected profile,
so that I can understand my care instructions and daily health actions.

## Business Value
- Directly improves medication adherence and comprehension.
- Demonstrates high personalization quality to judges.

## Acceptance Criteria
1. Medication questions return profile-grounded answers with relevant medication details.
2. Condition explanation questions return plain-language explanations linked to the active profile.
3. Response text avoids unnecessary jargon by default.
4. Assistant offers optional clarification prompts when concepts are complex.
5. Unsupported clinical diagnosis requests are not answered as factual diagnoses.
